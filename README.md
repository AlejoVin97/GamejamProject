Projecto Gamejam (Nombre por definir)

Repositorio del proyecto para la Game Jam #1 de la cohorte #13 de Generation Colombia (con participantes de Generation México).

-Manejar las branches de acuerdo al trabajo a realizar (mecánicas de juego en "Mecanicas", elementos gráficos en "Graficos", elementos de sonido en "Audio", funcionalidades y elementos narrativos en "Narrativa").
-"Niveles" es la branch en la cual se integran todas las otras ramas, y donde se realiza el diseño de los "niveles" de juego.
-Usar los medios de comunicación para avisar cuando se este trabajando en la branch "Niveles"
-Si alguna branch tiene a más de una persona trabajando sobre ella al mismo tiempo, utilizar escenas y carpetas distintas para el trabajo realizado sobre esta.
